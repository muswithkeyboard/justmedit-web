Кому предложить ферритин, если анемии нет

Модель скрининга оценивает по общему анализу крови риск низкого ферритина. Сдать ферритин предлагаем доле людей с наибольшим риском: чем больше доля, тем больше скрытых дефицитов найдём и тем чаще направление не подтвердится.

Референсы лаборатории

Необязательно. Впишите границы с бланка своей лаборатории — они заменят референс проекта по умолчанию (серым в полях). Пустое поле — значение по умолчанию. Единицы — как в форме выше. В отчёте врачу появится предупреждение, что использованы референсы лаборатории.
